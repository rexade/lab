# Taste Profile

*Stable preferences. Edit when taste changes, not every day.*

---

## Hard constraints (non-negotiable)

- **Super modern UI** — this is a hard constraint, not a vague wish
- Dark mode first, always
- Premium feel — like a high-end startup product or device console
- Minimal and confident — few strong elements, not many weak ones
- Reactive and alive — things should feel like they're breathing, not static

## What good looks like

- Strong spacing and breathing room
- Big clean typography with clear hierarchy
- Glassy or layered panels with depth
- Subtle glow accents on status/activity
- Smooth motion — transitions feel intentional, not decorative
- One or two bold focal areas per screen
- Feels like something people would actually want to touch

## What bad looks like (avoid at all costs)

- Enterprise admin panel aesthetic
- Generic dashboard grids of little cards
- Old-school Linux/sysadmin UI
- Ugly default buttons or form elements
- Tables used as primary UI
- Clutter — too many widgets, too much information density
- Retro or industrial styling
- Anything that looks like Bootstrap defaults

## Tech preferences

- React + Tailwind + shadcn/ui
- Framer Motion for animation
- Recharts or Plotly only when data actually needs it
- Self-contained — runs on a Pi
- No heavy dependencies without a real reason

## Recurring themes

- Alive and reactive — status that pulses, not just sits there
- Device console aesthetic — like a premium embedded system UI
- Minimal but confident — less is more, but what's there should be bold
