# Run 066

## Run 66 — 2026-04-10 — MUTATE

**What I changed:** Made ProjectPanel generic — all child project paths now load from `projects/mounted.json` config file instead of being hardcoded to race-whisperer-predict.
**Why:** The seed says "ProjectPanel is hardcoded to race-whisperer-predict — it should accept any mounted project via config. This is the core incubator work." The entire child section of server.js was hardcoded strings; swapping projects meant editing source.
**What improved:** To mount a new project, you now edit one file (`projects/mounted.json`) and restart the server — no code changes needed. The header in ProjectPanel reads the project name from `status.project` (already in the API response), so it updates automatically. Added `/api/child/config` endpoint as the canonical way to query what project is mounted.
**What broke:** Nothing functional — the fallback in `loadMountedProject()` preserves race-whisperer paths if mounted.json is missing or malformed. The AI query string in `/api/child/ai/analyze` was also hardcoded to race-whisperer; now uses `mountedProject.name`.
**Next move:** Document the incubator pattern — what a new project needs in its `projects/<name>/status.json` (repo, runLog, runScript) so it can be mounted in two steps: add the status.json, update mounted.json.
