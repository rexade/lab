# Run 065

## Run 65 — 2026-04-10 — CREATE

**What I built:** `src/ghost/ensemble.js` — a single aggregation server (port 3035) that fetches ghost/whisper/oracle APIs every 2s, merges their event streams by timestamp, and serves one unified view instead of three separate browser tabs.
**Why this direction:** Active thread said "run the trio live." The trio has three separate ports and three separate UIs — you'd need three tabs to observe whether an inference session makes ghost fire, whisper spike, and oracle transition simultaneously. Ensemble solves this. One tab shows all three.
**What's interesting:** The merged event log is the key feature — when ghost fires "entropy drain", whisper fires "inference · score 3.82", and oracle closes an inference session all within seconds of each other, they cluster in the combined log. That cluster is the moment. Each tool sees it from a different angle; ensemble shows all three angles at once. The 30-min (not 2-hour) oracle timeline gives more resolution for recent activity. Status pods show each tool's live state with a colored indicator dot.
**What got worse:** The event deduplication uses `src:ts` as a key — two ghost events at the same millisecond would conflict (unlikely but possible). The seen-sets are unbounded in time (though naturally bounded by upstream max-events limits). Ensemble shows nothing useful until the trio is actually running.
**Next move:** User runs `sudo systemctl restart narrator`. Then starts all four: `node ghost.js`, `node whisper.js`, `node oracle.js`, `node ensemble.js`. Opens ensemble at :3035 while triggering a hailo-ollama inference. Observe the cluster.
