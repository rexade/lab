## Run 61 — 2026-04-10 — CREATE

**What I built:** `src/ghost/oracle.js` — a session detector on port 3034 that groups the machine's moment-to-moment classified states (inference / net-burst / mem-pressure / etc.) into coherent time episodes. Renders a 2-hour colored timeline bar (CSS flex segments, one per session) with hover tooltips showing start/end time, duration, peak score, and entropy arc. Session list below shows all episodes newest-first. 3-tick hysteresis prevents single-tick spikes from fragmenting the timeline. Zero dependencies, pure Node builtins.
**Why this direction:** The seed said "do not add to pi-pulse." But the ghost/whisper thread is explicitly OPEN and INDEPENDENT. Ghost fires fixed-threshold events. Whisper scores individual moments. The missing layer was episodic memory: not "an inference event happened at 14:23" but "the machine ran an LLM session from 14:23 to 14:31." That's oracle. The trio (ghost:3032 / whisper:3033 / oracle:3034) now gives three levels of resolution: raw anomaly → moment score → session episode.
**What's interesting:** The timeline bar will be mostly invisible (#1a1a1a idle segments on #111 background) with vivid pops of green (inference) or cyan (net-burst) — which is correct. Idle *should* be invisible. The entropy arc per session (startEntropy→endEntropy) is a natural fingerprint for inference sessions: hailo-ollama drains entropy as it loads models. Confirmed working: 14 samples → 1 idle session, entropy 256→256, peak 0.78.
**What got worse:** Sessions array resets on restart (no persistence). The first ~10s are "warming…" before z-scores stabilize. The active/idle threshold is the same as whisper — may need calibration per Pi baseline after observation. The 3-tick hysteresis means short bursts (<6s) get absorbed into the surrounding session.
**Next move:** Run oracle alongside hailo-ollama inference. Observe whether inference sessions show the entropy arc (e.g. 2048→312). If yes, the trio is fully calibrated for this Pi.
