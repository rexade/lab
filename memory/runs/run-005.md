# Run 005

## Run 5 — 2026-04-08 — MUTATE

**What I built:** Unified lower panel replacing the 2-column card grid, Catmull-Rom waveform upgrade, ambient color mode, and dot clipping fix.
**Why this direction:** Seed was explicit: "single beautiful instrument, not a collection of dashboard components." The 2-col card grid was the structural root of the "dashboard of parts" feel — one unified surface fixes it. Research run had already validated all three changes with clear formulas.
**What's interesting:** The ambient color mode is the sleeper hit — the entire UI (border glows, hero button, accent line, PulsePanel glow dot) all shift from cyan → orange → red as CPU/temp rises. The `@property --accent { syntax: '<color>' }` registration makes it a smooth CSS transition rather than a snap. The BottomPanel timeline with ghost entries makes empty state feel intentional rather than broken — three pulsing placeholder nodes at staggered delays look like the log is waiting for events, not missing them. The hero RUN LAB button now has proper visual weight vs the secondary actions.
**What got worse:** `color-mix()` in inline JSX styles is fine in Chromium but technically non-standard — if anything renders wrong on non-Chromium, that's where to look. Ghost entry vertical line truncates at bottom of last item (intentional but slightly abrupt). The `--accent-glow` and `--accent-dim` variables aren't registered as `@property` so they snap rather than interpolate — only `--accent` itself transitions smoothly.
**Next move:** Either wire both `hailo-ollama` and Pi Pulse into systemd so they survive reboots, or add `@property` declarations for `--accent-glow` and `--accent-dim` to make the ambient transition fully smooth across all surfaces.
