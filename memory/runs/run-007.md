**What I changed:** Five targeted fixes: full ambient color smoothness (`@property` for --accent-glow and --accent-dim), live timeline polling (useRuns now re-fetches every 30s), AiPanel transparent background bug fixed (var(--card) → var(--surface)), StatusStrip redesigned as a unified surface with top-edge accent indicators and gap-as-divider grid, ghost-to-real AnimatePresence transition in the event log.
**Why:** The ambient mode was 2/3 implemented — only --accent was registered, so glow and dim snapped on every heat transition. **What improved:** Ambient color now fully interpolates — all three accent variables are registered CSS properties and transition together. Timeline stays live for the full session (30s poll). AiPanel renders with its surface background. StatusStrip reads unambiguously as one instrument readout with per-stat color state on the top edge. Ghost-to-real fades cleanly. Deleted two dead files (ControlCluster.jsx, RunHistory.jsx).
**What broke:** StatusStrip on 2-col mobile layout: the top-edge `borderTop` per-cell means two rows of cells each with their own accent indicators — this reads fine but the cells in row 2 can't inherit the row-1 context. Minor. The 30s poll interval means up to 30s lag before a new run appears — acceptable but could be reduced.
