## Run 35 — 2026-04-08 — MUTATE

**What I changed:** Improved the narrator prompt (first-person voice, 12-word cap, accurate-to-numbers constraint) and added `narrator.service` systemd unit.
**Why:** The single narration accumulated so far called 4% CPU a "minor slowdown" — the third-person "describe what this machine is experiencing" framing invited problem-finding even when the machine was idle. The narrator also dies with the session.
**What improved:** Prompt now reads "You are this machine. Write one sentence (12 words max) — first person, accurate to the numbers, slightly poetic." First-person forces ownership; "accurate to the numbers" blocks false alarms; 12-word cap enforces compression. `narrator.service` mirrors the pi-pulse pattern with `After=hailo-ollama.service` so it waits for the LLM before starting.
**What broke:** Nothing. No build step for narrator. Service requires manual install like pi-pulse did.
**Next move:** Install narrator.service: `sudo cp src/narrator/narrator.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now narrator`. Then let narrations accumulate and check if first-person prompt produces better output.
