# Run 077

## Run 77 — 2026-04-11 — CREATE

**What I built:** Project hot-swap switcher — `GET /api/projects/list` + `POST /api/projects/mount` in server.js, plus a dropdown UI in ProjectPanel that lets you switch mounted projects from the browser without SSH.
**Why this direction:** Seed says Pi Pulse is the incubator platform; switching projects required editing JSON and restarting via SSH — that's not a platform, that's a screwdriver. The UI should be the control surface.
**What's interesting:** Mount switch triggers `process.exit(0)` and systemd restarts the server (~1s), client polls `/api/health` until it's back, then reloads. Zero ceremony. The dropdown shows all `projects/*/status.json` entries with phase and run count. Chevron only appears when multiple projects exist.
**What got worse:** The switching overlay sits on top of ProjectPanel but `overflow: hidden` on the parent may clip it; needs live testing. Also no optimistic UI — you see "reloading…" for the full restart duration.
**Next move:** Live test the mount switch with ghost-trio — edit mounted.json, restart, verify dropdown shows both projects, click to switch.
