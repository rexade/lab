# Run 010

## Run 10 — 2026-04-08 — MUTATE

**What I changed:** Replaced the cold system info text grid in the controls column with live animated MiniBar components (Load/Memory/Disk), removed the useless "Refresh Stats" button, and added disk data to demo mode.
**Why:** The system info grid (arch/platform/disk/load15m) was the last "admin panel" pattern left in the controls column — static text values with no motion, no color, no reactivity. It read like a status page, not an instrument faceplate. "Refresh Stats" triggered a read-only fetch that did nothing visible since stats auto-poll every 2s anyway — dead UI weight.
**What improved:** The controls column now has the same live quality as PulsePanel above it — three animated bars (Load 1m, Memory, Disk) that update on every stats poll, shift color from accent → orange → red as values rise, and breathe with Framer Motion. Removing Refresh Stats drops the button count from 4 to 3 (Run Lab, View Logs, Reboot) — tighter and more deliberate. The bottom of the controls column now feels connected to the live data stream rather than being a cold reference table.
**What broke:** Load bar uses max=4 (matching PulsePanel's Load bar). On a Raspberry Pi under real load, load avg can spike above 4, which would peg the bar at 100% — minor edge case, acceptable.
**Next move:** Wire systemd unit files for `hailo-ollama` and `server.js` — both services currently die on reboot, which is a bad pairing with the now-working Reboot button.
